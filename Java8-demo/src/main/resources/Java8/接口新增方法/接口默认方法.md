# 介绍

> [!tip] 核心特性
> 接口默认方法是 Java 8 引入的新特性，允许接口定义默认实现的方法，使接口的演进更加灵活。与抽象方法不同，默认方法有具体的实现，实现类可以直接使用或选择重写。

接口默认方法的主要特点：
- 有默认实现，实现类可以直接使用
- 实现类可以选择重写默认方法
- 可以访问接口中的静态常量
- 不能访问实现类的实例变量
- 可以与静态方法共存

# 简单使用

## 基本语法

```java
interface MyInterface {
    void abstractMethod();
    
    default void defaultMethod() {
        System.out.println("默认方法");
    }
}
```

## 基本使用示例

```java
interface Vehicle {
    void start();
    
    default void honk() {
        System.out.println("Beep beep!");
    }
}

class Car implements Vehicle {
    @Override
    public void start() {
        System.out.println("Car starting...");
    }
    
    // 可以选择重写默认方法
    @Override
    public void honk() {
        System.out.println("Car honking: Beep beep!");
    }
}

public class Main {
    public static void main(String[] args) {
        Vehicle car = new Car();
        car.start();
        car.honk();
    }
}
```

## 接口多继承中的默认方法

当一个类实现多个接口，且这些接口有相同签名的默认方法时，实现类必须显式重写该方法以解决冲突。

```java
interface A {
    default void method() {
        System.out.println("A's method");
    }
}

interface B {
    default void method() {
        System.out.println("B's method");
    }
}

class C implements A, B {
    @Override
    public void method() {
        // 显式选择使用哪个接口的默认方法
        A.super.method();
        // 或者提供自己的实现
        System.out.println("C's method");
    }
}
```

## 静态方法与默认方法

接口中可以同时定义静态方法和默认方法，静态方法提供工具功能，默认方法提供实例相关的默认行为。

```java
interface Utils {
    static void staticMethod() {
        System.out.println("Static method");
    }
    
    default void defaultMethod() {
        System.out.println("Default method");
    }
}

public class Main {
    public static void main(String[] args) {
        // 调用静态方法
        Utils.staticMethod();
        
        // 调用默认方法需要实现类实例
        Utils instance = new Utils() {};
        instance.defaultMethod();
    }
}
```

# 最佳实践

1. **保持默认方法简单**：默认方法应该提供简单、通用的实现，避免复杂的业务逻辑
2. **避免状态依赖**：默认方法不应该依赖于实现类的内部状态，保持无状态
3. **使用默认方法进行接口演进**：当需要为接口添加新方法时，使用默认方法保持向后兼容
4. **显式重写冲突的默认方法**：当实现多个接口有冲突的默认方法时，显式重写并解决冲突
5. **文档化默认方法**：清楚地记录默认方法的行为和用途
6. **命名规范**：默认方法的命名应该清晰表达其功能，遵循 Java 命名规范
7. **访问控制**：根据需要选择适当的访问修饰符，通常使用 public
8. **避免过度使用**：不要为所有方法都提供默认实现，只用于适合的场景
9. **考虑性能**：默认方法的调用可能比直接方法调用稍慢，对于性能敏感的场景要注意
10. **与其他新特性结合**：可以与 Lambda 表达式、方法引用等 Java 8 新特性结合使用
